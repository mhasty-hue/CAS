# Email Template System

Templates are versioned through the event catalog and `notification_templates`.

Templates support:

- organization name
- recipient name
- property address
- order number
- product type
- due date
- inspection date
- bid deadline
- secure action button
- support/reply-to contact
- organization branding metadata

Ordinary users do not edit arbitrary raw HTML. Admin-editable fields should stay limited to safe subject, intro, closing, support contact, logo/branding, and reply-to values.

CAS-controlled privacy fields remain locked.
