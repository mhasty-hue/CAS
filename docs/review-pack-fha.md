# Review Pack: FHA Single-Family Overlay

Pack id: `pack-fha-single-family-overlay-v1`

The FHA overlay is selected only when the order/report indicates FHA applicability. It layers on top of the report profile and universal rules.

## Initial Checks

- FHA case or assignment identifier where extractable
- FHA condition and repair commentary
- Subject-to/as-is and repair-support consistency
- Order-specific FHA instructions

## Safety Limits

CAS does not determine FHA eligibility, create repair requirements from ambiguous text, or send FHA review findings to a client without reviewer approval. Judgment-heavy issues are phrased as reviewer questions and preserve source/version metadata.
