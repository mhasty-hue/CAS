# Review Pack: Legacy Conventional Single-Family

Pack id: `pack-legacy-conventional-single-family-v1`

This pack extends universal CAS QC for legacy 1004/URAR-style single-family reports.

## Initial Checks

- Subject address, client, report type, dates, signature, final value, required sections, and exhibits
- GLA, site size, bedrooms, and baths consistency
- Comparable sale and adjusted value completeness
- Net and gross adjustment math
- Signed certifications
- Reconciliation commentary
- Adjustment grid balance flag

## Review Posture

Objective missing data and arithmetic issues can be flagged directly. Comparable selection, reconciliation strength, and support language remain human-review prompts. CAS does not alter value conclusions.
