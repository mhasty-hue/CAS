# Review Pack: Estate / Retrospective

Pack id: `pack-estate-retrospective-v1`

This pack is for date-of-death, estate, and retrospective private-client assignments. It does not inherit mortgage-specific requirements unless the order requires them.

## Initial Checks

- Retrospective effective date matches the assignment
- Report/signature date is distinguishable from the retrospective effective date
- Post-effective-date data handling is disclosed
- Intended use/users and order instructions remain visible to the reviewer

Wrong effective date is critical. Methodology, post-effective-date data, and explanation issues remain human-review prompts.
